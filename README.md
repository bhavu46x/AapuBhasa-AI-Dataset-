> **A structured dataset to preserve and promote the Dehvali Aadiwasi (AapuBhasa) language using AI.**

---

## 📌 Project Overview
The **AapuBhasa AI Dataset** is part of the **AapuBhasa AI Project**, which aims to create:
- 🗣️ Translation tools  
- 🎙️ Speech recognition  
- 📖 Learning apps  
- 🤖 AI/ML language models  

This dataset is a **community-driven effort** to document and digitize our language for future generations.

---

## 📂 Dataset Structure
Each CSV entry contains:
- **id** → Unique identifier  
- **aapubhasa** → Word/Phrase/Sentence in Dehvali Aadiwasi  
- **english** → English translation  
- **hindi** → Hindi translation  
- **marathi** → Marathi translation  
- **category** → (Optional) e.g. daily-use, nature, culture
